1. Open **JFLAP** on your computer.

4. Use the relevant JFLAP simulation option to inspect or test the model.

## Learning Outcomes
The selected practicals cover:
- Designing deterministic and nondeterministic finite automata.
- Exploring DFA minimization.
- Representing regular languages using regular expressions and regular grammars.
- Converting a regular grammar into a DFA.
- Understanding stack-based computation using pushdown automata.
- Exploring computation using a one-tape Turing machine.

## Conclusion
JFLAP provides a visual and interactive environment for exploring abstract concepts in Theory of Computer Science. Working with these models helps connect formal definitions with state diagrams, transitions, grammars, and computational steps.
